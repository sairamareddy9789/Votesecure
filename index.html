Welcome to VoteSecure

A simple online voting system where voters can securely log in, view their dashboard, cast one vote and check election results.

🔐 Secure Login

Voter login uses Voter ID, name, email, mobile number and OTP.

☑️ One Voter • One Vote

The same voter cannot vote more than once in this demo.

📊 Admin Monitoring

Admin can monitor voters, completed votes, remaining capacity and candidate votes.

⚙️ Admin Control

Admin can control voting time and maximum number of voters.

Important Election Information

Review these points before starting the voting process.

🗳️ Election Details

Vote: One vote per registered voter

👤 Voter Eligibility

Use your valid Voter ID, registered email and mobile number.

📜 Voting Rules

Select exactly one candidate. After confirmation, your vote cannot be changed.

🛡️ Security

OTP verification is required before entering the voting dashboard.

⚙️ Voting Process

Login → OTP → Dashboard → Ready to Vote → Candidate → Confirm.

Do not share your OTP or voter details with anyone.
